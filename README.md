# TVS Motor Company – 3-Statement Financial Model

## 📌 Project Overview

This project presents a fully linked three-statement financial model for **TVS Motor Company**, a publicly listed Indian automotive company.

The model uses three years of historical financial data sourced from the company's annual reports and forecasts the company's financial performance for the next five years based on clearly defined operating and financial assumptions.

The objective is to demonstrate practical financial modelling skills, including historical financial analysis, financial statement linking, forecasting, assumptions building, and model integrity checks.

---

## 🎯 Project Objective

The model was developed to:

- Analyse TVS Motor Company's historical financial performance
- Build fully linked Income Statement, Balance Sheet, and Cash Flow Statement
- Identify key historical operating and financial trends
- Develop assumptions for future performance
- Forecast financial statements for five years
- Perform financial ratio analysis


---

## 🏢 Company

**TVS Motor Company Limited**

TVS Motor Company is one of India's leading two- and three-wheeler manufacturers, with operations across domestic and international markets.

---

## 📊 Model Structure

The Excel model contains the following key sections:

### 1. Historical Financial Statements
Three years of historical financial data covering:

- Income Statement
- Balance Sheet
- Cash Flow Statement

### 2. Ratio Analysis

Key financial ratios are calculated to evaluate:

- Profitability
- Liquidity
- Solvency
- Efficiency
- Return metrics

### 3. Drivers 

Historical trends are used to develop assumptions for the forecast period, including:

- Revenue growth
- Operating margins
- Expense assumptions
- Tax rate
- Working capital
- Capital expenditure
- Depreciation
- Other key operating drivers

### 4. Forecast

The model forecasts three years of:

- Revenue
- Operating expenses
- EBITDA
- EBIT
- Profit Before Tax
- Net Income
- Assets
- Liabilities
- Equity
- Cash Flow

The forecast statements are linked to the underlying assumptions and drivers.

---

## 🔗 Three-Statement Linkage

The model follows a three-statement structure where the financial statements are interconnected.

For example:

**Income Statement → Net Income → Cash Flow Statement**

**Cash Flow Statement → Ending Cash → Balance Sheet**

**Net Income → Retained Earnings → Balance Sheet**

This allows changes in operating assumptions to flow through the entire financial model.

---

## ✅ Model Checks

The model incorporates financial statement checks to improve accuracy and ensure consistency.

Key checks include:

- Balance Sheet balancing
- Cash Flow Statement reconciliation
- Cash balance reconciliation
- Retained earnings consistency


The objective is to ensure that the model remains internally consistent when assumptions are changed.
